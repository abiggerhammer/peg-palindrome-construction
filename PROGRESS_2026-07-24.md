# Progress: retained Lemma 3.3 and factored source machine

This update closes the persistent-background gap identified in the previous
archive.

## New operational properties

- `SGZeroRatioMachine()` now defaults to the explicit Algorithm-Y tape backend
  for RECOVER, LOCAL, and BACKGROUND.
- The normal runtime path does not call the direct palindrome/B3 oracle,
  Z/Manacher, or the indexed Lemma-3.3 implementation.
- `audit=True` restores those routines only as differential assertions.
- The case-3 LOCAL worker freezes at most `4d` symbols, matching the
  Fine--Wilf reduction in the paper rather than rescanning the entire suffix.
- Lemma 3.3 retains one checkpoint scan, catches it up, and follows its period;
  it is not restarted at every prefix.
- The outer SG case selection and inner Lemma-3.3 phase selection are exported
  as literal finite tables.
- A source trace can be run through Galil's literal scheduler table.  Tests
  include a trace that genuinely enters SLOW mode and emits speculative zeros.
